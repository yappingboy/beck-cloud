# cms

**Purpose:** Directus headless CMS deployment.

**What it does:** Hosts Directus 13.0.2, a self-service content management platform for media metadata and structured content. Exposed at `cms.becklab.cloud` with admin SSO. The namespace contains the Directus service and its backing PostgreSQL and Redis instances, providing an API-first CMS.

**Status:** Active — pods present and serving traffic.
