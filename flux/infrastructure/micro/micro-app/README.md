# micro/micro-app

**Purpose:** Microservices platform

**What it does:** Auth-service deployment with RBAC, TLS certificate, middlewares, and ingress routes.

**Services:**
- `auth-service` — Auth-service (Deployment, Service, ConfigMap, Role, RoleBinding, Secret, ServiceAccount)
- `middlewares` — Traefik Middleware
- `ingressroutes` — IngressRoute
