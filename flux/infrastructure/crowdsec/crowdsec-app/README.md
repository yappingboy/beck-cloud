# crowdsec/crowdsec-app

**Purpose:** WAF + IP reputation protection

**What it does:** Crowdsec HelmRelease, Traefik Bouncer middleware (stream mode), and secret key configuration.

**Services:**
- `helmrelease` — Crowdsec HelmRelease
- `bouncer-middleware` — Traefik Middleware
- `secrets` — Crowdsec secret
