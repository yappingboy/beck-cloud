# 3dprinting

**Purpose:** 3D printing management and slicing services

**What it does:** Hosts 3D printing workflow tools — model viewers (Manyfold, BumpMesh), remote slicers (OrcaSlicer, FDM Monster), and print management (SpoolMan).

**Special resources:** PostgreSQL database for Manyfold (via secretGenerator), PVCs for model files and HTML assets.
